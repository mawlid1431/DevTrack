DEVTRACK BRAND ASSETS
=====================
Logo: "Board". A bold D holding three columns that rise from left to right: to do, doing, done.
The last column is always Done Green.

Core colors
  Deep Navy   #0B1B2E   main color, text, dark backgrounds (dark mode uses navy, never pure black)
  Done Green  #16C784   accent, primary buttons, "done" states
  Mist        #F2F6F4   soft light background
  White       #FFFFFF

The logo is the mark alone. There is no wordmark: when the name is needed, write "DevTrack" in Inter SemiBold.

Folders
  logos/transparent   no background, PNG 32 to 2048 px + SVG
  logos/on-navy       Deep Navy background baked in (white logo)
  logos/on-white      white background baked in (color / navy logo)
  logos/small-size    simplified two-column mark for 16 to 32 px
  Variants: color (light backgrounds), white (navy/dark backgrounds), navy-mono, white-mono (one-color use)
  app-icons/navy         main app icon, rounded, all sizes 16 to 1024
  app-icons/navy-square  same, square corners, for App Store / Play Store (they round it themselves)
  app-icons/white, green alternative tiles
  favicon/               favicon.ico (16/32/48), favicon.svg, PNG sizes, apple-touch-icon, Android, maskable, manifest
                         head-snippet.html has the exact <head> tags
  social/                Open Graph, Twitter/X, GitHub, LinkedIn banners and profile avatar

Rules in short: never stretch, rotate or recolor the mark; the third column is always green;
use the white version on navy; keep clear space equal to the height of the D's top bar (13/72 of mark height) x 2.
Full rules: DevTrack-Brand-Guidelines.pdf
